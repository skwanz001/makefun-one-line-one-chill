A single horror sentence, entered in make.fun's "One Line, One Chill" bounty. `main.py` (standard library only) writes one 112-character line to `/output/entry.txt`: a spare key gone from under the mat, replaced by a tooth, still warm. No setup, no second chance — the dread is in what the line withholds.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
